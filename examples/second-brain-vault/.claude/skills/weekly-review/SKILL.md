# Weekly review

1. Read the last 7 daily notes in `Journal/` and any notes created or modified in the last 7 days.
2. Check `01-Projects/`: which moved forward, which have had no updates in 14+ days (stalled)?
3. Fill in `Templates/Weekly Review.md` and save it as `Reviews/YYYY-MM-DD-weekly-review.md`:
   - 🏆 Wins (be specific and generous)
   - 📚 What I learned (link the notes)
   - 🧱 Stuck or stalled (kindly, with one suggested next step each)
   - 🎯 Top 3 for next week
4. End with one encouraging sentence. Keep the whole review under 300 words.
