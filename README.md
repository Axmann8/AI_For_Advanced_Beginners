# 🚀 AI for Advanced Beginners: The Massive Manual

### *You know what an LLM is. You know how to prompt. Now what?*

A **40+ chapter**, hands-on field guide to the **fun part** of AI: connecting it to your apps with MCP, automating your life
with n8n/Zapier/Make, building your own tools and agents, running models on your own machine, making art and music, and
using all of it for real work and real life. Plus **working starter kits** you can run in minutes.

There's no "what is a large language model" and no "10 rules for better prompts." You've got that. This is what comes next. 🎉

## ⚡ Quick Start: Your First Superpower in 5 Minutes

```bash
git clone https://github.com/Axmann8/claude_cloud_trial_credits && cd claude_cloud_trial_credits/examples/my-first-mcp-server
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python smoke_test.py            # 🎲 🥠 it works!
claude mcp add pocket-toolkit -- "$(pwd)/.venv/bin/python" "$(pwd)/server.py"
claude                          # then: "roll 4d6 and give me a fortune"
```

## 🌐 About the website

The manual is published with [MkDocs Material](https://squidfunk.github.io/mkdocs-material/) via GitHub Actions
([`.github/workflows/site.yml`](.github/workflows/site.yml)).

- **Turn it on (one time):** repo **Settings → Pages → Source: GitHub Actions**. Every push to `main` then redeploys it.
- **Preview locally:** `pip install -r requirements-docs.txt && mkdocs serve` → http://127.0.0.1:8000
- **Adding a chapter?** Drop a Markdown file into the right `manual/part-*` folder and run `python scripts/sync_manual.py`
  to regenerate the navigation and "Next →" links.
- **One giant file:** `python scripts/build_single_file.py` writes `MANUAL.md`.
